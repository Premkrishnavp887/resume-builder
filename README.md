## Quick Start

### 1. Get your Anthropic API key
Go to https://console.anthropic.com and copy your API key.

### 2. Backend setup
```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-your-key-here   # Windows: set ANTHROPIC_API_KEY=...
python app.py
```
Backend runs on http://localhost:5000

### 3. Frontend setup (new terminal)
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on http://localhost:5173

### 4. Open the app
Visit http://localhost:5173 in your browser.

## How it works
1. Fill in your details (or paste JSON/text)
2. Paste the job description
3. Click Build — the Flask backend calls the Anthropic API to tailor the resume
4. Download the ATS-optimized PDF generated by ReportLab
